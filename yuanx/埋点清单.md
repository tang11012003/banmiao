# 陪读社区埋点清单

> 版本：v1.2 · 2026-08-04
> 命名规范：`模块_对象_动作`，动作统一用 view / tap / submit / success / fail / confirm / cancel
> 所有事件均携带用户公共属性（见第十一节）。

## 十二、优先级说明

| 级别 | 含义 | 建议实现时机 |
|---|---|---|
| P0 | 核心转化链路，缺失会导致关键数据断裂 | 上线前必须完成 |
| P1 | 主流程行为，支撑核心指标分析 | 首个数据版本完成 |
| P2 | 细节交互，用于深度行为分析 | 迭代版本逐步补齐 |

## 十三、命名规范

- 格式：`模块_对象_动作`
- 动作词统一：

| 动作词 | 含义 |
|---|---|
| `view` | 页面 / 内容曝光 |
| `tap` | 点击操作（不含表单提交） |
| `submit` | 表单 / 内容提交（发起请求前） |
| `success` | 操作成功（服务端回调后） |
| `fail` | 操作失败 |
| `confirm` | 二次确认弹窗点击确定 |
| `cancel` | 取消操作 |
